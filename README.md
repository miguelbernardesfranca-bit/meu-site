# Eletric Motors ⚡

Site institucional da Eletric Motors, uma empresa fictícia de motos elétricas sustentáveis.

## Sobre o projeto

O projeto apresenta a empresa, sua história, seus produtos,
seus diferenciais ambientais e formas de contato.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Estrutura

- `index.html` — estrutura do site
- `style.css` — estilos e aparência
- `script.js` — funcionalidades e validações

## Objetivo

Criar uma página moderna para apresentar uma empresa
de veículos elétricos e sua proposta sustentável.
